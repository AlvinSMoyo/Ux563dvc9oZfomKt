## 📊 Power BI Dashboard

This dashboard complements the machine learning pipeline by offering visual insights into customer behavior and campaign effectiveness.

👉 [Term_Deposit_Marketing_Dashboard.pbix](Term_Deposit_Marketing_Dashboard.pbix)

### Key Tabs:
- **Campaign Overview**: Conversion trends by call duration, attempts, and contact type
- **Customer Demographics**: Age and occupation analysis
- **Financial Behavior**: Account balance and loan status correlations
- **Segment Prioritization**: Identifies ideal customer groups for future outreach

Built using: **Power BI Desktop**
